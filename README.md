# 🇪🇬 Egypt Experience Builder (2026)

An interactive, discovery-based travel planning tool designed to help travelers navigate the trade-offs of visiting Egypt. 

Instead of a prescriptive "Yes/No" quiz, this tool allows users to visualize the "Art of the Possible" by adjusting their preferences for flights, accommodation, food, and excursions.

---

## 📖 How to Use

1.  Open the [Live Demo](https://aaronkchan.github.io/trip-builder/).
2.  Adjust the sliders to match your travel style.
3.  Review the "Realities" section to ensure you are prepared for the environment.
4.  Join the linked communities to finalize your itinerary!


## 🚀 Features

* **Live Budget Calculator:** Real-time 7-day cost estimates based on 2026 travel data.
* **Trade-off Exploration:** Interactive sliders that dynamically update "Possibility Cards" to show exactly what a Budget vs. Premium experience looks like.
* **The Reality Check:** A dedicated section on non-negotiable travel truths (Water safety, heat pacing, and "Hustle Culture" strategies).
* **Community Hand-off:** Curated links to active travel communities on TripAdvisor, Reddit, and Facebook for real-time ground updates.

## 🛠️ Tech Stack

* **HTML5 / Vanilla JavaScript:** Core logic and state management.
* **Tailwind CSS:** Modern, responsive UI styling via CDN.
* **GitHub Pages:** Automated deployment and hosting.

## 📈 Product Philosophy

This project shifted from a traditional "Gatekeeper Quiz" to a "Discovery Engine." The goal was to reduce user friction and decision fatigue by framing constraints as choices rather than obstacles. It prioritizes **transparency** (showing real costs) and **empowerment** (mitigation strategies for common travel pain points).
